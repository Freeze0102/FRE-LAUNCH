# FRE LAUNCH — пошук контенту в самому лаунчері

## Modrinth

У Java-збірках і каталозі доступний пошук модів, модпаків, ресурс-паків і шейдерів без веббраузера. Modrinth використовує власний каталог та інсталятор лаунчера. Встановлені моди Java зберігаються в папці відповідної збірки; готові `.mrpack` створюють окрему збірку.

У незалежній React-версії Java-бібліотеки каталог також відкривається безпосередньо на сторінці вибраного профілю. Після встановлення вміст файлів оновлюється.

## CurseForge

У каталозі «Моди» та «Модпаки» можна переключити джерело на CurseForge. Пошук виконується **всередині FRE LAUNCH** через офіційний CurseForge API. Перехід на сайт замість пошуку прибраний.

Важливо: сторонній програмі потрібен **схвалений API-ключ CurseForge**. Його можна ввести на поточну сесію у розділі «Налаштування доступу CurseForge» або задати середовище `FRE_CURSEFORGE_API_KEY`. Без затвердженого доступу CurseForge не повертає результати, і лаунчер чесно показує помилку: **не використовує парсинг HTML, чужі ключі чи фальшивий каталог**.

- Java-моди з дозволом на стороннє розповсюдження можна встановити прямо у вибраний сумісний профіль. Інсталятор перевіряє файл, версію Minecraft, модлоадер, SHA-1 та обмеження розміру.
- CurseForge-модпаки доступні для внутрішнього пошуку, але **повне встановлення ZIP-модпаків ще не підтримується**. Такі результати не мають кнопки фальшивого встановлення.
- Modrinth залишається робочим без CurseForge API-ключа. Автоматичне вирішення всіх конфліктів між модами не гарантоване.

Офіційні правила отримання API-доступу: https://support.curseforge.com/support/solutions/articles/9000208346-about-the-curseforge-api-and-how-to-apply-for-a-key

## Minecraft (Rust) і Horizon

Java `.jar` моди з Modrinth/CurseForge не можуть запускатися на нативному Rust-клієнті. Для двох типів Rust-профілів («Minecraft на Rust» та збережених Horizon) «Файли» тепер відкривають внутрішню панель з категоріями «Моди», «Ресурс-паки», «Шейдери», «Світи», «Журнали» й «Усі файли», пошуком за назвою та відкриттям папки Windows як додатковою дією. Панель читає файли лише обраного профілю, не переходячи за символічними посиланнями.

Horizon-клієнт стартує напряму з FRE LAUNCH, від'єднаний від термінала та успадкованої групи Ctrl+C. Офіційний `horizon-launcher.exe` залишається допоміжним компонентом для перевірки встановлених профілів, підготовки ресурсів та оновлень. Для Play не потрібно тримати CMD/PowerShell відкритим.

Наявність панелі файлів **не означає**, що Rust-клієнт підтримує Java JAR або має офіційний каталог нативних модів.

## Перевірка

Вихідний код має регресійні тести для внутрішнього пошуку, відхилення старих результатів, встановлення лише дозволених модів, списку файлів Rust/Horizon та обмеження шляхів. Під час оновлення потрібно запустити тестовий набір, перевірку типів і збирання збереженого Modrinth-форка. Живе встановлення CurseForge вимагає свого схваленого API-ключа, а Horizon — встановленої гри на Windows. Зелений статус CI сам по собі не доводить, що Minecraft правильно запуститься на конкретному комп'ютері.
