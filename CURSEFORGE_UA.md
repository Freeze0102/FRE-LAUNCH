# FRE LAUNCH — CurseForge + Modrinth (локальна розробка)

## Стан

У каталозі `Моди` є перемикач **Modrinth / CurseForge**.
У кожній модифікованій Java-збірці (Fabric, Forge, NeoForge, Quilt)
під вкладками є кнопка **«Знайти моди CurseForge для цієї збірки»**:
вона відкриває пошук уже з ID цієї збірки, не змушуючи повторно
шукати її в переліку.
Modrinth працює як раніше. CurseForge використовує офіційний API,
потребує схваленого ключа та дозволу автора на стороннє розповсюдження.
У вкладці **Модпаки** також можна вибрати **CurseForge** та знайти збірки.
Для цих ZIP-модпаків наразі доступні пошук та перехід до сторінки автора;
автоматичне встановлення не імітується, тому кнопки інсталяції немає.

### Як перевіряти локально

1. Зберіть лаунчер локально через `FRE-LAUNCH-LOCAL.cmd`. GitHub Actions не потрібні.
2. Відкрийте `Моди` → `CurseForge`.
3. Виберіть уже створену збірку Fabric, Forge, NeoForge або Quilt.
4. Вставте ваш **схвалений** CurseForge API-ключ у поле поточної сесії
   або перед запуском задайте змінну середовища `FRE_CURSEFORGE_API_KEY`.
5. Шукайте мод. Кнопка встановлення доступна лише для дозволених проєктів.
6. Лаунчер перевіряє версію Minecraft, модлоадер, розмір, SHA-1 і структуру JAR;
   імпортує дозволений файл через штатне сховище вмісту цієї збірки.
   Для імпорту закрий гру; повторний файл або ім'я не замінюються.

API-ключ не зберігається у профілі, не надсилається на Modrinth,
не записується у логи. Не вставляйте чужі ключі й не публікуйте ключ
у репозиторії. Офіційні умови та запит на доступ:
https://support.curseforge.com/support/solutions/articles/9000208346-about-the-curseforge-api-and-how-to-apply-for-a-key

**Що ще не зроблено:** інтегрований імпорт ZIP-модпаків CurseForge,
автоматичне встановлення обов'язкових залежностей
CurseForge, виявлення конфліктів між модами, готова публічна API-інтеграція
без власного схвалення. Наявність сумісних версій модів не гарантує
відсутності конфліктів. Перед змінами робіть резервну копію збірки.
Якщо ключа немає, доступне посилання на офіційний каталог CurseForge,
але не автоматичне завантаження.

## Minecraft на Rust (Horizon)

Minecraft на Rust відображається в тій самій бібліотеці, що й Java-збірки,
але використовує інший рушій, свої папки й нативні моди.
**Java JAR-моди CurseForge на Rust-клієнті не працюють.** Тому кнопка
інтегрованого CurseForge-інсталятора з'являється тільки в сумісних
Java-збірках. Старі Horizon-збірки й їхні файли збережено.
Деталі: [FRE_RUST_NATIVE_UA.md](FRE_RUST_NATIVE_UA.md).

Офіційний проєкт: https://playhorizon.dev/ .

- GitHub Actions не запускали; готовий Windows NSIS-реліз не випускався.
