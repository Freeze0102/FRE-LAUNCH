# FRE LAUNCH native Minecraft — перевірка 04.11.2026

Це звіт локальної перевірки Windows x64, а не дозвіл на автоматичний реліз.
GitHub Actions для цієї роботи не запускалися. Реліз і updater-канал не публікувалися.

## Що знаходиться в репозиторії

- Усі **4174 вихідні файли** MIT-проєкту `horizon-rust/horizon` із коміту
  `975c07d9151847e6af13afc4b5ab37b6bbe78ef5`, зі збереженням Git blob-хешів,
  executable/symlink modes, `LICENSE` та сторонніх повідомлень про ліцензії.
- Незмінене upstream-дерево: `85268b86aaa57415fbb2c8d784d7a375b4b44d82`.
  Додатковий `FRE-VENDORED-SOURCE.json` описує імпорт; `native_source.py` перевіряє
  кожен файл і реконструює незалежно зафіксований Git tree.
- Інтеграція FRE LAUNCH: власні Rust-профілі, створення/перейменування/іконки,
  підтверджене видалення, окремі світи/файли/логи, локальні `.hmod`, приватна
  підготовка ресурсів і прямий запуск клієнта через stdin-сесію Minecraft.
- Повний код зовнішнього launcher збережений тільки як частина незмінного MIT
  snapshot; він не збирається, не пакується й не запускається FRE LAUNCH.
- У Git та інсталятор не додаються Minecraft JAR, текстури, звуки, акаунти,
  токени або підготовлені приватні ресурси. Пакувальник відмовляється приймати
  каталог `resources` у runtime.

## Виправлені причини попередніх збоїв

- Windows tar зупиняв імпорт на `CLAUDE.md` symlink; Git archive також змінював
  LF на CRLF. Новий імпорт перевіряє повний Git tree та точні bytes/modes.
- Локальна збірка вимагала вже видалені Horizon-патчі, пропускала preparer
  і працювала за іншими правилами, ніж CI. Тепер використовується один пакувальник.
- Генератор дублював `sha1`/`zip` у Cargo.toml і додавав неоднозначний `reqwest`
  у Cargo.lock. TOML та locked Cargo перевірки тепер це виявляють.
- TypeScript generics потрапляли у JavaScript `<script setup>` головного App.vue.
- Старі тести вимагали `horizon.rs` і попередні дозволи, яких більше немає.
- Mojang перевидала version JSON 03.11.2026. Пошук лише актуального маніфесту
  блокував чисте встановлення; список альтернативних asset index також не містив
  основного pinned index. Тепер запитується точний content-addressed маніфест,
  а індекс перевіряється за дескриптором у цьому маніфесті.
- Кеш із кількома основними файлами міг здаватися готовим. Тепер перевіряються
  schema/output-version, необхідні файли та хеші, а перед запуском — preparer `--check`.
- Зміна PNG на інший PNG не оновлювала мініатюру; додана ревізія іконки.
  Asset protocol має вузькі дозволи лише на три raster-файли native-профілю.
- Історичні сторонні записи Defender помилково блокували будь-який новий файл.
  Сканер перевіряє результат actual scan, незмінність файла і всі detection-записи
  саме для цього output. Історія Defender не очищається, захист не вимикається.

## Межі перевірки

Користувач сам авторизував Minecraft-акаунт у тестовій конфігурації й запустив гру.
Володіння грою не підмінялося офлайн-ніком чи фіктивним токеном. Паролі/токени
не отримувалися агентом, авторизація не автоматизувалася. Під час першого запуску
`sessionserver.mojang.com/session/minecraft/hasJoined` повертав HTTP 503; пізніше
вхід, підготовка й запуск відбулися. Це спостереження тесту, не діагноз глобальної аварії Mojang.

Користувач зупинив Computer Use фізичною Esc, тому подальше керування вікнами
припинено. Гру й підготовлені ресурси не закривали та не видаляли. Останній
патч показу іконок потребує повторної візуальної перевірки після наступного
звичайного запуску оновленого інсталятора; активну гру заради цього не переривали.

Не виконувалися сотні vanilla parity harnesses з приватними Minecraft-даними та
повний набір тестів усіх upstream workspace. Перенесений конкретний upstream-коміт
залишається експериментальною реалізацією Minecraft; цей звіт не доводить повної
відповідності кожної механіки чи роботи на всіх GPU.

Публікація релізу, підписаного оновлення або розповсюдження через release feed
залишається окремою явною дією після схвалення. Попередній security hold не знято.
Команди повторення: [TESTING.md](TESTING.md), [інструкція збірки](FRE_RUST_NATIVE_UA.md).
