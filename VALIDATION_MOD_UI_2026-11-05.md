## Зміни

У 0.5.13 в одній вкладці одночасно відображалися великі картки вбудованих
модів, каталог і два файлові списки. У 0.5.14 основний екран — звичайний
компактний список установлених і вбудованих модів. **Додати моди** відкриває
окремий каталог із поверненням до збірки. Пошук/сторінка зберігаються при
відкритті та закритті опису, а також при поверненні до списку збірки.

Використані ті самі готові компоненти, що й у звичайних Java-збірках:
`ContentCardTable`, `ProjectCard`, `ProjectCardList`, `Input`, `Combobox`,
`NavTabs`, `Pagination`, `NewModal`, кнопки й меню. Java API встановлення
JAR не викликається для Rust-профілів.

- Іконки, назви, автори та версії файлів у спільному списку.
- Справжні перемикачі, пошук, фільтр, сортування за назвою/версією.
- Вибір кількох рядків, групове ввімкнення/вимкнення й видалення файлів
  із підтвердженням; вбудовані моди захищені від видалення.
- Налаштування зуму в меню його рядка; вбудовані FPS та XYZ перемикаються поруч.
- Додавання кількох `.hmod` через меню над списком.
- Каталог із пошуком, сортуванням, списком/сіткою й сторінками по 20/40/80.
- Картка проєкту відкриває **Опис / Версії / Результати перевірки**.
- Для підтриманого пакета даних кнопка **Установити** сама запускає перевірку,
  потім установлення та активацію. Окрема ручна перевірка більше не обов’язкова.
  Невдала перевірка відкриває звіт і не виконує встановлення.
- Вбудовані варіанти FRE мають кнопку **У збірці**, що веде до їх налаштувань.

## Стан у самій грі

Перемикачі пакетів використовують справжній `fre-mods.txt` із записами
`mod.<id>:true/false`, який читає зафіксований рушій. Файли модів не
перейменовуються й не перепаковуються; підписи та записи встановлення зберігаються.
Встановлення/імпорт увімкне підтриманий пакет для наступного запуску.

Увімкнення повторює перевірки встановлених файлів перед зміною стану.
Пошкоджений пакет не стає ввімкненим. Перевірки походження, SHA-256, відкликань,
підписів, ZIP та Defender з 0.5.13 залишаються обов’язковими.

Зміна стану зберігається через синхронізований тимчасовий файл і безпечну заміну.
Інші рядки налаштувань, клавіші, коментарі, профілі та світи не переписуються.
Пошкоджений, завеликий або небезпечний шлях налаштувань не замінюється мовчки.
Назви/автори імпортованих архівів обмежені за розміром перед передачею в GUI.
Під час гри зміни відхиляє і інтерфейс, і backend. Пізній результат іншого
профілю не змінює поточний екран; підтвердження видалення прив’язане до профілю.

## Межі

Інтерфейс приведений до звичайних збірок; сумісність модів визначається Rust-рушієм.
Сторонні нативні `.hnmod` доступні для перегляду й перевірки, але потребують
окремої переглянутої сумісної збірки FRE. Вони не виконуються автоматично.
Установлюються підтримані пакети даних API 0.2. Ресурсний пакет-компаньйон
не замінює відсутню нативну частину. NBT без валідатора та невідомі формати
відхиляються; паки/шейдери поки доступні для перегляду. Сканування та підписи
не є гарантією безпечності коду. [Перевірки каталогу](VALIDATION_CATALOG_2026-11-05.md).
Новий вхід Microsoft із завантаженням усіх ресурсів з нуля не повторювався.
