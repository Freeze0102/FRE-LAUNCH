# Horizon (Rust) у FRE LAUNCH

## Що додано

У **Створити збірку → Horizon (Rust)** додано справжню інтеграцію з
офіційним Horizon CLI. Це не ще один Java-модлоадер і не копія файлів Horizon.

- Користувач сам вибирає `horizon-launcher.exe` з офіційного Windows ZIP.
- Створення збірки: `horizon-launcher instance create "<назва>"`.
- Перегляд збірок: `horizon-launcher instance list`.
- Запуск: `horizon-launcher play --instance "<назва>"`.
- Локальна діагностика: `horizon-launcher logs --lines 120`.
- Перегляд інстальованих версій: `horizon-launcher versions --installed`.
- Установлення версії: `horizon-launcher install latest` або за тегом випуску.
- Призначення версії збірці: `horizon-launcher instance version "<назва>" "<версія>"`.
- Підготовка ресурсів гри: `horizon-launcher prepare`.
- Для конкретного встановленого тега форма передає `prepare --version <тег>`;
  додатково можна вибрати папку Minecraft для `--minecraft <папка>`.
- Список установлених версій, оновлення та інші налаштування
  залишаються за офіційним Horizon launcher.
- Java-профілі Modrinth/Fabric/Forge і файли Horizon зберігаються окремо.

У формі зберігається тільки шлях до вибраного exe в локальних налаштуваннях
інтерфейсу. Паролі, Microsoft-токени й акаунти Horizon не переносяться у FRE LAUNCH.

## Як користуватися

1. Завантажити **Windows x64** із [офіційного сайту](https://playhorizon.dev/docs/install) та розпакувати ZIP.
2. У FRE LAUNCH натиснути **Створити збірку → Horizon (Rust)**.
3. Вибрати `horizon-launcher.exe` (не завантажений лаунчером автоматично).
4. Назвати збірку й натиснути **Створити Horizon-збірку**.
5. Встановити потрібну версію Horizon через кнопку **Установити версію**, потім підготувати Minecraft 26.3 через **Підготувати ресурси**. Перед цим установити та хоча б раз запустити Minecraft: Java Edition 26.3 у звичайному лаунчері. Вимоги до акаунта визначає відповідний офіційний випуск Horizon; FRE LAUNCH їх не обходить.
6. За потреби вибрати версію для створеної Horizon-збірки кнопкою **Вибрати версію**, тоді натиснути **Грати через Horizon**.

Офіційні команди: https://playhorizon.dev/docs/api/launcher .
Світові й профільні файли Horizon за замовчуванням належать Horizon, а не
Java-збіркам FRE LAUNCH. Для перенесення світів робити резервні копії.

## Про помилки в самому Horizon

Це експериментальний сторонній Rust-клієнт. Поточна інтеграція **не усуває
помилки Horizon**. Вони виправляються у його рушії, не в коді FRE LAUNCH.

Якщо щось не запускається, натиснути **Показати логи Horizon** у вікні
створення/запуску Rust-збірок і перевірити повідомлення. Логи читаються
локально — нічого автоматично нікуди не надсилаємо.

Повідомлення про помилки Horizon: https://github.com/horizon-rust/horizon/issues .
Для нашого зв'язку з Horizon — баги розглядати у FRE LAUNCH, вказавши:
версію Horizon launcher, версію гри, кроки відтворення та лог без токенів.

**Обмеження:** Java JAR-моди Fabric/Forge/NeoForge/Quilt не працюють у Horizon,
а власні Horizon native-моди не встановлюються у Java-збірки.

## Перевірки

Актуальні локальні перевірки й обмеження: [AUDIT_UA.md](AUDIT_UA.md).
Windows Rust check та окрема збірка Vue перевіряються локально;
аргументи команд і помилки — ізольованим тестовим CLI.
Справжній офіційний Horizon і гра **не запускалися**. Повний strict TypeScript
gate ще не проходить. Інтеграція залишається експериментальною.
GitHub Actions не запускали; витрат хвилин CI немає.
