# FRE LAUNCH 0.5 Alpha — FIELD NOTES

**Your Minecraft. Your Rules.** Неофіційний лаунчер Minecraft Java Edition для Windows 10/11 x64. Стек: Tauri 2, Rust, React, TypeScript.

## Два інсталятори — який вибрати?

Відкрий [GitHub Actions](https://github.com/Freeze0102/FRE-LAUNCH/actions), обери останню **успішну** збірку **Windows Build** для `main`, прокрути до **Artifacts**.

- **FRE-LAUNCH-Windows-Installer** — рекомендований інсталятор **для поточного користувача**, не повинен вимагати права адміністратора.
- **FRE-LAUNCH-Windows-Admin-Installer** — альтернативний інсталятор, дозволяє встановити для всіх користувачів, вимагає UAC/права адміністратора.
- **FRE-LAUNCH-Windows-Portable** — EXE без інсталяції. Налаштування та Minecraft все одно зберігаються в даних користувача Windows.

Архів Artifacts — це ZIP. Його треба розпакувати перед запуском EXE.

### Встановлення на диск D:

У стандартному інсталяторі можна вибрати папку **`D:\FRE LAUNCH`**, якщо є дозвіл Windows на запис. Не встановлюй безпосередньо в корінь `D:\`. Якщо раніше використовував системний інсталятор, спочатку закрий усі вікна FRE LAUNCH.

Під час CI стандартний інсталятор не тільки збирається, а й запускається в тихому режимі із власною тимчасовою директорією на Windows runner. **Це перевірка лише на конфігурації GitHub, не доказ успішного встановлення на конкретному диску користувача.**

Папка встановлення EXE та папка гри — різні речі: **Minecraft, світи та ресурси можуть і далі зберігатися в AppData на диску C:**. Їх не можна переносити простим переміщенням інстальованого EXE.

## Новий інтерфейс FIELD NOTES

У версії 0.5 головна сторінка має власну редакційну композицію з авторським SVG-піксельним ландшафтом, великим блоком запуску, смугою швидких функцій, компактною навігацією та читабельним каталогом. Доступні п'ять кольорових варіантів. Попередні налаштування зберігаються локально.

## Як запустити Minecraft

1. На сторінці «Профілі» створи офлайн-нікнейм.
2. На сторінці «Версії» обери Vanilla (для першої перевірки краще звичайний release).
3. Натисни **Встановити / перевірити** або кнопку на головній.
4. Після справжнього завершення завантаження натисни **Грати зараз**.
5. Для Vanilla 1.21.4 потрібна Java 21. У параметрах є виявлення і менеджер Java.
6. Для Fabric/Quilt та модів створи окрему збірку й вибери сумісний модлоадер.

Offline-профіль не обходить серверну перевірку придбаної ліцензії Minecraft.

## Якщо натискання «Встановити» призводить до помилки

**У самій програмі:** FRE LAUNCH 0.5 записує початок і результат встановлення до локального журналу, не дозволяє кілька одночасних встановлень і перехоплює частину внутрішніх помилок Rust. Відкрий **Діагностика** → **Читати журнал** → **Копіювати помилки**. Якщо інтерфейс був пошкоджений помилкою React, з'явиться екран відновлення з можливістю перезапустити вікно й скопіювати помилку.

**У зовнішньому Windows-інсталяторі:** внутрішній журнал FRE LAUNCH ще не створений. Використай стандартний неадміністративний інсталятор замість адміністративного, спробуй каталог у своїх правах доступу, наприклад `D:\FRE LAUNCH`. Якщо Windows інсталятор закривається без повідомлення, шукай помилку через Windows Event Viewer → Windows Logs → Application.

Повний виліт операційної системи, сторонній антивірус або несправний диск не можна виправити лише React-кодом.

## Що вже в коді

- Офіційний Mojang manifest, клієнт, бібліотеки, SHA-1-перевірка, живий прогрес.
- Встановлення Vanilla й запуск через сумісну Java в офлайн-режимі.
- SQLite-збірки з окремими світами, RAM і Java; локальні профілі.
- Fabric, експериментальний Quilt, Modrinth-пошук, Fabric-моди та ресурс-паки з перевіркою контрольних сум.
- Java Manager з виявленням і керованим завантаженням Eclipse Temurin.
- 3D-студія скінів, піксельний редактор, серверний пінг, PNG-галерея, резервні копії світів.
- Локальна діагностика помилок та два Windows-інсталятори.

## Чого ще немає або не перевірено

- Microsoft OAuth, підтвердження Minecraft ownership.
- Forge і NeoForge, повне покриття всіх старих версій.
- Повноцінний протестований запуск реальної гри на всіх Windows-машинах, зокрема на ПК користувача.
- Повна локалізація, автоматичне підписане оновлення та вибір окремого каталогу для **ігрових файлів** на D:.

Не плутай зелену GitHub Actions-збірку з підтвердженням успішного запуску Minecraft на твоєму ПК.

## Для розробників

Потрібні Node.js 22, Rust stable, Windows WebView2, Windows build tools. Команди:

```bash
npm install
npm run check
cargo test --manifest-path src-tauri/Cargo.toml
npm run tauri icon src-tauri/icons/app.svg
npm run tauri build
```

GitHub Actions додатково збирає варіант з адмін-правами та перевіряє тихе встановлення стандартного інсталятора у тимчасову папку.
