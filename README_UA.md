# FRE LAUNCH 0.2.0 Alpha

**FRE LAUNCH — Your Minecraft. Your Rules.**

Це відкритий проєкт Minecraft Java Edition launcher для Windows 10/11.

## Встановлення з телефона

1. Відкрий вкладку **Actions** репозиторію GitHub.
2. Вибери останню успішну збірку **Windows Build**.
3. Унизу сторінки завантаж **FRE-LAUNCH-Windows-Installer**.
4. Розпакуй ZIP на комп'ютері та запусти інсталятор.

Якщо збірка червона або архів відсутній — готового інсталятора ще немає.

## Розробка

Потрібні Node.js 22, Rust stable, Windows WebView2 та залежності Tauri 2.

```bash
npm install
npm run tauri icon src-tauri/icons/app.svg
npm run tauri dev
```

Для збірки:

```bash
npm run tauri build
```

## Наявна функціональність (альфа)

- Список реальних релізів, снапшотів та історичних версій Mojang.
- Пошук та вибір версії.
- Початковий завантажувач клієнта, бібліотек та ресурсів із перевіркою SHA-1.
- Спроба запуску локального Minecraft через встановлену Java.
- Локальний офлайн-нікнейм, обсяг RAM, живі логи й індикатори завантажень.
- Перевірка Java, яку видно в PATH.

**Важливо:** збірка та запуск гри ще не підтверджені тестуванням на Windows. Історичні версії можуть не працювати. Microsoft-авторизація та модлоадери не готові.

## Як запустити

1. Відкрий FRE LAUNCH.
2. На сторінці «Акаунти» задай локальний нікнейм.
3. Вибери Minecraft Release у розділі «Версії».
4. Натисни «Встановити / перевірити».
5. Після завершення повернися на головну та натисни «Грати».
6. Якщо Java несумісна, встанови потрібну версію Java до PATH та перезапусти лаунчер.
7. При помилках відкрий «Логи» й надішли повідомлення розробнику.

Офлайн-профіль не підтверджує володіння ліцензією Minecraft та не обходить захист офіційних серверів.
