## Що додано

Живий каталог у вкладці «Моди» Rust-профілю: пошук за назвою/автором/тегами,
фільтри типу, іконки, версії, автори, ліцензії, описи, посилання на GitHub,
поступове відображення списку та результати перевірки кожного файла.
Вхід до іншого лаунчера не потрібен. Описи відображаються як звичайний текст.

Під час перевірки публічний реєстр містив **94 проєкти**: 85 native-mod,
3 mod, 1 resourcepack, 5 shader. Джерело:
[публічний індекс](https://horizon-rust.github.io/horizon-mods/index.json),
[репозиторій реєстру](https://github.com/horizon-rust/horizon-mods).
Кількість є спостереженням на дату перевірки, а не зафіксованим списком.

Автоматична перевірка перед установленням та запуском сторонніх `.hmod`:

- лише HTTPS і дозволені GitHub/CDN переходи, точна належність release проєкту;
- свіжий реєстр відкликаних версій, розмір, SHA-256;
- Minisign-підпис за зафіксованим ключем автора; 36 ключів включені до FRE;
- маніфест і відповідність версії/ID/API каталогу, формат пакета;
- межі архіву: 32 MiB download, 4096 записів, 8 MiB на файл, 128 MiB expanded;
- заборона traversal, дубльованих шляхів, links, Windows device paths і
  прихованих PE/ELF; обмеження текстур, перевірка JSON;
- завершений scan Microsoft Defender, перевірка виявлень і повторний хеш;
- перевірка встановленого файла за записом установлення перед грою.

Відкриття опису мода запускає перевірку його пакета; кнопка «Перевірити файл»
дозволяє повторити її. Установлення завжди повторює перевірки зі свіжим індексом.
Старий збережений каталог доступний для читання; установлення без свіжого
з’єднання заблоковане. Defender unavailable/error/detection також блокує
установлення. Непідписаний файл позначається застереженням, новий/змінений ключ
потребує нового перегляду FRE. Окремі ліміти захищають і читання локальних файлів.

Файл і його запис спочатку зберігаються в тимчасових файлах із синхронізацією,
потім публікуються без перезаписування вже встановленого мода. Видалення прибирає
відповідний запис перевірки; інші моди й світи залишаються на місці.
Імпорт перевіряє власну тимчасову копію, а не змінюваний вихідний файл.
Зміна профілю під час запиту не переносить результат чи установлення в інший профіль.

## Межі

Перевірки підтверджують походження/цілісність файла і виявляють певні відомі
проблеми. Вони **не є гарантією безпечності коду**, повним аудитом або доказом
сумісності готової гри. GitHub-посилання саме по собі не підтверджує безпечність.
Defender використовується через
[офіційний інтерфейс Microsoft](https://learn.microsoft.com/en-us/defender-endpoint/command-line-arguments-microsoft-defender-antivirus?view=o365-worldwide).

85 нативних модів — source-mixin пакети, що потребують окремої перевіреної
компіляції сумісної гри FRE. Каталог **не виконує їхній код і не встановлює їх
як готові моди**. Сканування та текстові індикатори process/network/unsafe
допомагають огляду, але не замінюють його. Вбудовані зум, FPS та XYZ залишаються
готовими до гри; вони не видаються за встановлені сторонні проєкти.

Установлюються лише підтримані пакети даних API 0.2 без native/WASM-коду.
Пакет-компаньйон сам не додає механіки відсутнього нативного мода; залежність
показана в описі. Minecraft-функції пакета можуть впливати на світ.
Застарілий executable `.hmod`, NBT без валідатора та інші невідомі формати
відхиляються. Ресурс-паки й шейдери наразі доступні для перегляду.

За відсутності `.hmod` старт гри не залежить від реєстру/Defender;
вбудовані моди працюють без зовнішнього каталогу.

відхилене зі збереженням попередніх байтів. Валідний ZIP із навмисно зміненою

нативний Zoom і запит із застарілим SHA-256 відхилені. Тестовий `world.dat`
залишився незмінним. Сторонній нативний код не компілювався й не запускався.

GitHub/reqwest повертав тимчасовий HTTP 504 для одного справжнього release asset.
Додано обмежену повторну спробу й Windows system HTTP fallback; ті самі дозволені
hosts/redirects/розміри/хеші залишаються обов’язковими. Реальні перевірки та
встановлення пройшли з цим шляхом. URL і файл передаються через environment,
а текст PowerShell фіксований; дані каталогу не вставляються в shell-код.
