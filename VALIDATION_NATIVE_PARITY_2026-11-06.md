# Перевірка FRE LAUNCH 0.5.15 — 06.11.2026

Версію з виправленнями нативних збірок зібрано для Windows x64 і встановлено в
`C:\Users\andri\Downloads\FRE-LAUNCH-App`. Робочий репозиторій розташований у
`C:\Users\andri\Downloads\FRE-LAUNCH`, поза OneDrive. Реліз на GitHub і автоматичне
оновлення не публікувалися; GitHub Actions не запускалися.

## Що змінено

- **Моди:** підтримані `.hnmod` встановлюються кнопкою в каталозі. Перед грою
  FRE збирає всі ввімкнені нативні моди разом власним керованим компілятором.
  Окремі launcher/account або системні Rust і Visual Studio гравцю не потрібні.
  Застарілий абзац каталогу про окрему кнопку Build прибрано з відображення;
  автори, ліцензії, посилання на джерела та перевірені метадані не змінені.
- **Зум:** утримання C, зміна дистанції коліщатком 1–64×, відповідна чутливість
  миші, звичайний огляд після відпускання. Коліщатко не змінює слот хотбару.
  Початкове наближення, клавіша, FPS і координати застосовуються без перезапуску.
- **Акаунт і вкладки:** прибрано зайвий перемикач збереженого акаунта на
  Rust-сторінці, вибір Java-акаунта/нікнейма впорядковано. «Уміст» активний одразу.
- **Світи:** спільні картки, пошук і фільтри світів/серверів, серверні статуси,
  додавання та підтверджене видалення сервера з `servers.dat`, прямий Play для
  вибраного світу/адреси. Rust-ID не передається Java-менеджеру.
- **Журнали:** спільна консоль, поточний лог з оновленням, пошук, рівні,
  розгортання й історія, включно з датованими `.log.gz`. Розмір читання обмежено.
- **Гра:** лічильник тривалості, останній запуск, збереження часу при виході
  та кожні 30 секунд, червона кнопка Stop, нативний процес у верхній панелі.
  Зупинка стосується дочірнього процесу вибраної збірки.

Виправлено також помилку Windows при додаванні сервера: тимчасовий файл
залишався відкритим під час атомарного запису `servers.dat`, через що виникало
`Access denied (os error 5)`. Тепер дескриптор закривається перед записом;
регресійний тест виконує додавання, повторне додавання та видалення.

## Джерела й пакування

Рушій залишається зафіксованим на MIT-ревізії
`975c07d9151847e6af13afc4b5ab37b6bbe78ef5` у `vendor/fre-rust-source`.
Повне MIT-джерело інструмента модів додано в `vendor/fre-mixins-source`
на ревізії `a2af5c0dd4117d51ecd70066ba7a00b4a2c10dab` з пофайловим походженням.
Оригінальні LICENSE обох джерел збережені.

Інсталятор містить гру, підготовлювач, інструмент модів та детермінований
ZIP дозволених MIT-джерел. Пакет джерел виключає `.local`, приватні експорти
ресурсів, збірочні кеші та сторонні локальні файли. Пропрієтарні Minecraft-ресурси
до інсталятора/репозиторію не включені. Вони готуються приватно після перевірки
володіння Minecraft; сесія передається грі через stdin.

Компілятор Rust 1.99.1 та MinGW завантажуються з перевіркою закріплених SHA-256
у приватний кеш FRE. Нативний build перевіряє фактично ввімкнені пакети, їхні
підписи/записи/відкликання, поєднує підтримані ігрові hooks, компілює гру,
сканує EXE Defender і зберігає перевірений результат для повторного запуску.

## Реальні запуски гри та встановленого UI

На GPU запущено обидва варіанти гри, зі створенням/збереженням власного тестового
світу та нормальним виходом:

| Варіант | Кадри | Чанки | Секції mesh | Тривалість |
| --- | --- | --- | --- | --- |
| Вбудований клієнт | 2014 | 49 | 744 | 56,28 с |
| Власна GNU-збірка з Fullbright | 1550 | 49 | 745 | 50,73 с |

В обох перевірено C → 4×, коліщатко → 8×, зміну налаштування на 6× під час
гри та повернення до 1× у меню/після відпускання. Слот хотбару не змінився.
Нативний мод у зібраній грі підтвердив реальне виконання повідомленням
`[Fullbright] Gamma set to 700%`.

Через справжній Tauri IPC у встановленому EXE перевірено:

- початкове зелене «Уміст» і відсутність старого перемикача акаунта;
- активну кнопку встановлення та фактичне завантаження/ввімкнення `.hnmod`
  `fullbright` (поточна назва каталогу MoreGamma), без хибного «FRE build required»;
- відсутність застарілої інструкції про сторонню кнопку Build;
- додавання сервера формою UI, появу картки та реальний запис у `servers.dat`;
- читання контрольного `.log.gz` й відкриття спільної консолі.

Відокремлений WebView тесту не містив Microsoft-сесії та приватного підготовленого
кешу. Тому запуск з акаунтом через кнопку UI, його живий таймер і фактичний колір
Stop під час цієї сесії **не оголошуються пройденими end-to-end**. Відповідні
контракти/стани покривають Cargo/Node-тести; GPU-запуски гри описані окремо вище.
Підключення до зовнішнього публічного сервера в цій перевірці не виконувалося.

Тестова збірка `1793912004460055000` містила лише власні QA-файли та порожній
`saves`. Після завершення тесту видалено тільки цю перевірену папку; інші ID
профілів залишилися незмінними. Відмова production-захисту видалення для
MSIX-alias тестового контексту не обходилася послабленням захисту застосунку.

## Відомі межі

Підтримується Minecraft 26.3 зафіксованого рушія. Java JAR-моди Fabric/Forge
несумісні з цим клієнтом. Нативні пакети з додатковими crates, postbuild/build
scripts, цілями поза game-модулем, новішими hooks або старим WASM блокуються
з поясненням. Каталог може містити такі пакети: наявність у списку не означає
сумісність з цією ревізією. Resource packs/shaders поки доступні для перегляду.

Нативний код працює з правами користувача: SHA-256, підпис, структурна перевірка
та Defender не є гарантією безпечності. Час гри обліковується для сесій, які
відстежує запущений лаунчер; давня історія до появи обліку не вигадується.
Імена сторонніх проєктів, джерела та обов'язкові юридичні атрибуції збережені;
окремий сторонній launcher/account для роботи FRE не потрібний.
